Embodied data collection playground

BoxGPT

BoxGPT is a simplified testbed for embodied data collection. A mobile binary sensor moves across a planar space to locate a hidden rectangle. A measurement is positive when sampled from within the rectangle and negative otherwise.

From the accumulated signals, BoxGPT infers a distribution of rectangles consistent with the data and quantifies predictive uncertainty across the space. The task is to design a feedback control policy that uses this information while accounting for sequential data collection and motion constraints.

Mathematical formulation

From model uncertainty to robot actions

BoxGPT is a simplification of a general problem in embodied data collection. We are learning a generative model, denoted by \(p(y\mid x;\theta)\), where \(x\) is the state of the robot, \(y\) is the variable of interest and the variable of measurement, and \(\theta\) is the parameter of the model. For example, \(y\) could represent an image in a vision model.

Learning from sequentially collected data

The robot moves across the space to collect data. Each data point is denoted by \(d_i=(x_i,y_i)\), and the accumulated dataset is \(D=\{d_i\}_{i=1}^{N}\). Model regression infers a distribution of model parameters, denoted by \(q(\theta\mid D)\), from this dataset. Maximum likelihood estimation can be considered a special case in which this distribution is a Dirac delta function.

Given an inferred parameter distribution, the posterior predictive distribution at a robot state \(x\) is

\[ \bar p(y\mid x,D) = \mathbb{E}_{\theta\sim q(\theta\mid D)}\!\left[p(y\mid x;\theta)\right]. \]

We quantify its predictive uncertainty using an information function \(h(x)\):

\[ h(x)=\mathbb{H}_{y}\!\left[\bar p(y\mid x,D)\right], \]

where \(\mathbb{E}\) denotes expectation and \(\mathbb{H}\) denotes entropy. The information function describes how uncertain the current model is at a particular robot state. More generally, the expected information that a measurement provides about the model parameters is

\[ \mathbb{I}(y;\theta\mid x,D) = h(x)-\mathbb{E}_{\theta\sim q(\theta\mid D)} \!\left[\mathbb{H}_{y}\!\left[p(y\mid x;\theta)\right]\right]. \]

In BoxGPT, every rectangle predicts the binary measurement deterministically, so the second term is zero. Predictive entropy and expected information gain are therefore equivalent for this problem.

Data collection is a decision-making problem

The remaining problem is how to use the information function to generate robot actions. Data collected by a robot is inherently sequential, and the robot's motion is constrained by its dynamics. It cannot independently sample every informative state. Its current action affects both the next measurement and which measurements will be reachable afterward.

BoxGPT is designed to highlight these challenges and serve as a testbed for prototyping data-collection policies for embodied agents. It makes model regression tractable so that the challenge lies in the data-collection policy rather than the capability of the model. This exposes the role of decision-making in data collection, which is often overlooked relative to model architecture.

The BoxGPT model

In BoxGPT, the measurement \(y\in\{\text{Positive},\text{Negative}\}\) is binary, and the predictive model is a Bernoulli distribution:

\[ p(y\mid x;\theta)= \begin{cases} g(x;\theta), & \text{if }y\text{ is Positive},\\ 1-g(x;\theta), & \text{if }y\text{ is Negative}. \end{cases} \]

The parameter \(\theta\) fully characterizes a rectangle, and \(g(x;\theta)\) indicates whether the robot state is within that rectangle:

\[ g(x;\theta)= \begin{cases} 1, & x\in\operatorname{Rectangle}(\theta),\\ 0, & \text{otherwise}. \end{cases} \]

Analytical model regression

Given \(D=\{(x_i,y_i)\}_{i=1}^{N}\), define \(\Theta(D)\) as the set of rectangle parameters that include every positive measurement and exclude every negative measurement. The inferred distribution is uniform over this consistent set:

\[ q(\theta\mid D)\propto \mathbf{1}\!\left[\theta\in\Theta(D)\right]. \]

The environment represents this distribution with sampled candidate rectangles. In the interactive demonstration, these are the red rectangles. Each new measurement removes candidates that are no longer consistent with the accumulated data.

An intuitive uncertainty distribution

Let \(r(x)\) be the fraction of inferred rectangles that include a state \(x\):

\[ r(x)=\mathbb{P}_{\theta\sim q(\theta\mid D)} \!\left[x\in\operatorname{Rectangle}(\theta)\right]. \]

The information function is therefore the binary entropy

\[ h(x)=-r(x)\log r(x)-\bigl(1-r(x)\bigr)\log\bigl(1-r(x)\bigr). \]

A state has no uncertainty when all inferred rectangles agree on its label. It has the highest uncertainty when exactly half of the rectangles include it and the other half do not. The random, greedy, and ergodic policies above provide three different ways to turn this spatial information into robot motion.
